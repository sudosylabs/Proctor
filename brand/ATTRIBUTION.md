# Typeface attribution

The wordmark outlines are retained from the existing Proctor artwork and
come from IBM Plex Sans Medium (SIL Open Font License). This attribution
applies to the standalone wordmarks and the lettering in the horizontal and
vertical lockups. No font file is included in this pack.

The SVG artwork preserves the corresponding typeface attribution in its
source. Repository licensing is described in [LICENSING.md](../LICENSING.md).
