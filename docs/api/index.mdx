## Use the Contract as the Authority

The docs build publishes `openapi.json` directly from the tracked server
contract. It does not infer endpoints from handlers or rewrite canonical
descriptions. The generated reference is a reader for that contract, never a
second source of route behavior.

Browse the endpoint groups in the sidebar. Every endpoint page is generated
from the same contract and displays its authentication, idempotency, and stable
error-code declarations before the request and response schemas.

If this is your first integration, begin with [Getting Started](./guides/getting-started.mdx),
then read [Authentication and Assurance](./guides/authentication.mdx) and
[Errors and Problem Details](./guides/errors.mdx). The remaining guides cover
pagination, safe retries, uploads, protected content, realtime recovery, and
compatibility.

The [end-to-end recipes](./recipes/bootstrap-installation.mdx) connect those
rules into real workflows: installation bootstrap, academic structure,
invitations, Exam publication, Sitting control, candidate Attempts, integrity
review, and audit consumption.

## Read Every Operation Completely

Each route declares its credential requirement through `x-proctor-auth`.
Security-sensitive operations may additionally require a strong, recently
authenticated interactive <Term id="session">Session</Term> and CSRF proof; a
<Term id="personal-access-token">Personal Access Token</Term> is not
interchangeable with that assurance.

Public failures use RFC 9457 Problem Details and stable application codes.
Operations declare their bounded codes in `x-proctor-error-codes`, and agreement
tests require them to map to documented HTTP responses.

## Contract Conventions

- Request and response objects are closed unless a named extension point is
  deliberately open.
- Collection traversal uses bounded opaque keyset cursors.
- Resource mutations authorize the current <Term id="principal">principal</Term>
  against current durable state at the terminal use case.
- Idempotent commands distinguish exact replay from reuse with different input.
- Successful durable state commits before transient cache, cluster, or realtime
  effects.

Read the [HTTP contract conventions](https://github.com/sudosylabs/Proctor/blob/main/server/httpapi/CONTRACT.md)
before generating a client or designing an integration.
