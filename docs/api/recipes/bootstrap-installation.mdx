# Bootstrap an Installation

Bootstrap is a one-time installation transition. It creates the Institution,
the first administrator account, and the authority needed for subsequent
configuration.

## 1. Check Bootstrap State

Call <Link to="/api/reference/get-installation-status">Get installation bootstrap status</Link>
without credentials. Continue only when the response says the installation is
not bootstrapped.

## 2. Submit the Bootstrap Secret Once

Obtain the bootstrap secret through the operator-controlled installation
channel. Do not put it in a URL, shell history, source file, or support log.

```bash
curl --request POST \
  --url https://proctor.example.edu/api/v1/bootstrap \
  --header 'Content-Type: application/json' \
  --data '{
    "institution": {
      "name": "northbridge-university",
      "display_name": "Northbridge University",
      "description": "Examination services"
    },
    "administrator": {
      "username": "initial-admin",
      "email": "initial-admin@example.edu",
      "display_name": "Initial Administrator",
      "locale": "en",
      "timezone": "Europe/Paris"
    },
    "password": "<strong-one-time-bootstrap-password>",
    "bootstrap_secret": "<operator-provided-bootstrap-secret>"
  }'
```

See <Link to="/api/reference/bootstrap-installation">Bootstrap installation</Link> for the
current password, locale, and field constraints. The example values are
synthetic.

## 3. Establish a Normal Session

After a successful bootstrap, discard the bootstrap secret from client memory
and use <Link to="/api/reference/login">Login</Link> to establish the administrator's normal
interactive Session. Bootstrap is not a reusable sign-in mechanism.

## 4. Verify and Continue

Read the bootstrap status again, then fetch <Link to="/api/reference/get-institution">the Institution</Link>
with the new Session. Continue with the [Academic Structure recipe](./academic-structure.mdx)
and configure admission policy through a preflight before replacing it.

If two bootstrap requests race, only the authoritative transition can succeed.
Treat an already-bootstrapped response as a definitive state, not as a reason
to retry with a different secret.
