# Read an Explicitly Released Result

Submitting an Attempt does not immediately publish an integrity Review. An
authorized Exam Manager must complete every required non-academic disposition,
finalize the Review, and explicitly release the candidate projection.

Before release, the result is concealed as not found. This prevents an
unreleased Review from leaking through status, timing, or partial content.

After release, Proctor shows only the approved student-facing remarks together
with the Review, Submission, and Attempt identities and the release time. It
does not expose:

- Integrity Flags, evidence, or discrepancies;
- manager decisions, private rationales, or private notes;
- the sealed Submission manifest or file contents; or
- a grade, score, rubric, pass/fail, or academic outcome.

An integrity disposition is not a declaration of guilt and is not a grade.
Your Institution owns any academic process outside this narrow Proctor result
projection.

If a result was announced but remains unavailable, confirm that you are using
the same account and Institution as the Attempt, then contact the Institution.
Do not ask support staff to send private Review content through email or chat.
