# Take an Exam With Proctor Desktop

Candidate delivery is available only through a compatible, registered-key
Proctor Desktop Session. An ordinary browser Session or copied bearer token
cannot enter an Attempt.

## Know What the Status Means

An Exam Activity card is a navigation projection, not a permanent admission
grant. It may classify a Sitting as upcoming, available, in progress,
submitted, result available, or past and expose only current safe actions such
as enter, resume, or view result. Admission still rechecks Class membership,
Sitting state, build compatibility, Desktop Registration, and current Session.

Proctor records protected programming-exam delivery and integrity signals. It
does not decide a grade, score, rubric, pass/fail, or guilt.
